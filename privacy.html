Privacy policy

Last updated: 2026-10-29

Kilas Studio is a personal tool run by the owner of the YouTube channel Kilas (@kilas-101). Only that owner signs in to it.

Data accessed

With the owner's consent, Kilas Studio uses the YouTube Data API scope youtube.force-ssl to upload videos to the owner's own channel, set their privacy status and publish time, upload thumbnails, add caption tracks, and read the status of those videos.

Storage and sharing

OAuth tokens are stored only on the owner's own computer. Kilas Studio has no server, stores no Google user data elsewhere, and does not sell, share, or transfer Google user data to any third party.

Kilas Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses the YouTube API Services, subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions.
